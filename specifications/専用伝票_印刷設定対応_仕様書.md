# 専用伝票 印刷設定対応 仕様書

作成日: 2026-06-07

## 1. 背景と課題

### 現状
- Local Printer の `printPdf()` が全プラットフォームでA4用紙サイズをハードコードしている
- 専用伝票（例: チェーンストア統一伝票）はカスタムサイズ（304.8mm x 127mm）のPDFとして正しく生成されているが、印刷時にA4として送られるため、現場でプリンタ設定を手動変更している

### ゴール
- 伝票種別マスタ（`/master/slip-type`）に印刷設定を追加し、専用伝票の印刷時に自動で正しい用紙サイズ・向き・拡縮を適用する
- 既存のA4伝票（自社伝票、A4の専用伝票）の動作は一切変更しない

## 2. 現在のアーキテクチャ

### PDF生成フロー（AI-CORE側 — 変更不要）

```
earnings画面「印刷」→ PrintSelectorModal
  → PdfExport::handle()
    → earning毎にBuyerDetail.slip_type_idを確認
      ├─ 自社伝票 (INTERNAL) → CreateClientSlipV2 (A4, 余白あり)
      └─ 専用伝票 (DEDICATED) → SpecificSlipRegistry で振り分け
           ├─ 登録済み → 各専用Action (例: CreateChainStoreTurnaroundSlip)
           │    → setNewPage() で独自ページサイズ設定済み
           └─ 未登録 → CreateDefaultSpecificSlip (A4)
```

各専用伝票Actionは既にページサイズ・向き・余白を個別にオーバーライドしている。
例: `CreateChainStoreTurnaroundSlip` — 304.8mm x 127mm, Landscape, 余白0

### 印刷ジョブフロー

```
PdfExport → S3アップロード → DocumentSlipPrintOutput作成(STANDBY)
  → Local Printer polling(/api/printer/polling)
    → GetPrinterJobs: STANDBY取得 → ENDにマーク
      → DocumentPrintOutputVO としてレスポンス
        → Local Printer: S3ダウンロード → printPdf() → OSプリンタ
```

### 問題箇所: Local Printer `printPdf()` (main.js:200-272)

| プラットフォーム | 現在のコード | 問題 |
|---|---|---|
| Windows (pdf-to-printer) | `paper=A4,fit,shrink` | A4固定 |
| Windows (SumatraPDF) | `paper=A4,fit` | A4固定 |
| macOS/Linux (lp) | `-o media=A4` | A4固定 |

## 3. 実装計画

### 3.1 AI-CORE: `slip_types` テーブルに印刷設定カラム追加

**ファイル**: 新規マイグレーション

| カラム | 型 | デフォルト | 説明 |
|---|---|---|---|
| `paper_size` | string(20) | `'A4'` | `'A4'` または `'custom'` |
| `custom_paper_width` | decimal(6,1) | null | カスタム時の幅 (mm) |
| `custom_paper_height` | decimal(6,1) | null | カスタム時の高さ (mm) |
| `print_orientation` | string(20) | `'auto'` | `'auto'` / `'portrait'` / `'landscape'` |
| `print_scaling` | string(20) | `'fit'` | `'fit'` / `'shrink'` / `'noscale'` |

- 既存レコードは全てデフォルト値（A4, auto, fit）→ 動作変更なし
- `paper_size = 'A4'` の場合、`custom_paper_width/height` は無視
- `paper_size = 'custom'` の場合のみ `custom_paper_width/height` を使用

### 3.2 AI-CORE: `document_slip_print_outputs` テーブルに `slip_type_id` 追加

| `slip_type_id` | unsignedBigInteger | null | 伝票種別への参照 |

### 3.5 AI-CORE: UpdateSlipType — 新パラメータ保存

**ファイル**: `app/Actions/Updaters/UpdateSlipType.php`

```php
public function handle(
    string $model_cls,
    ?int   $id,
    ?string $code,
    string $name,
    ?int   $category,
    ?int   $max_detail_count,
    ?string $paper_size,           // 追加
    ?float  $custom_paper_width,   // 追加
    ?float  $custom_paper_height,  // 追加
    ?string $print_orientation,    // 追加
    ?string $print_scaling,        // 追加
): ActionResult
{
    $item = $this->saveItem($model_cls, $id, $code, $name);
    $item->category = $category ?? ESlipTypeCategory::INTERNAL->value;
    $item->max_detail_count = $max_detail_count ?? 6;
    $item->paper_size = $paper_size ?? 'A4';
    $item->custom_paper_width = $custom_paper_width;
    $item->custom_paper_height = $custom_paper_height;
    $item->print_orientation = $print_orientation ?? 'auto';
    $item->print_scaling = $print_scaling ?? 'fit';
    $item->save();
    return ActionResult::withResult(new SimpleDataVO($item->id));
}
```


`fromModel()` でslip_typeをロードして印刷設定を構築:

```php
$print_settings = null;
if ($output->slip_type_id) {
    $slipType = \App\Models\SlipType::find($output->slip_type_id);
    if ($slipType && $slipType->paper_size !== 'A4') {
        $print_settings = [
            'paper_size' => $slipType->paper_size,
            'paper_width' => $slipType->custom_paper_width,
            'paper_height' => $slipType->custom_paper_height,
            'orientation' => $slipType->print_orientation,
            'scaling' => $slipType->print_scaling,
        ];
    }
}
```

A4の場合は `print_settings = null` → Local Printer側でデフォルト（A4）動作

### 3.7 Local Printer: `printPdf()` に印刷設定パラメータ追加

**ファイル**: `main.js` (printPdf関数 line 200)

```javascript
async function printPdf(printerName, localFilePath, printSettings = null) {
```

#### Windows (pdf-to-printer)

```javascript
// printSettings がある場合はカスタム設定を使用
const paperSetting = printSettings
    ? `paper=${printSettings.paper_width}x${printSettings.paper_height}mm`
    : 'paper=A4';
const scaleSetting = printSettings?.scaling || 'fit';

const result = await printerLib.print(localFilePath, {
    printer: printerName,
    win32: [`-print-settings "${paperSetting},${scaleSetting}"`]
});
```

#### Windows (SumatraPDF直接)

```javascript
const paperSetting = printSettings
    ? `paper=${printSettings.paper_width}x${printSettings.paper_height}mm`
    : 'paper=A4';
const scaleSetting = printSettings?.scaling || 'fit';

const args = [
    '-print-to', printerName,
    '-print-settings', `${paperSetting},${scaleSetting}`,
    localFilePath
];
```

#### macOS/Linux (lp)

```javascript
const mediaSetting = printSettings
    ? `Custom.${printSettings.paper_width}x${printSettings.paper_height}mm`
    : 'A4';
const orientationOpt = printSettings?.orientation === 'landscape'
    ? '-o orientation-requested=4'
    : '';

const cmd = `lp -d "${printerName}" -o media=${mediaSetting} -o sides=one-sided ${orientationOpt} "${localFilePath}"`;
```

#### 呼び出し側の変更

ポーリングレスポンスから `print_settings` を取り出して渡す:

```javascript
await printPdf(printerName, job.localPath, job.print_settings);
```

## 7. 影響範囲

- **自社伝票**: 影響なし（slip_type_id未設定 or paper_size='A4' → print_settings=null）
- **A4の専用伝票**: 影響なし（デフォルト値のまま → print_settings=null）
- **カスタムサイズ専用伝票**: マスタ画面で設定後、自動で正しいサイズで印刷
- **ピッキングリスト**: 影響なし（print_type='picking' にはslip_type_idなし）
- **PDF生成ロジック**: 変更不要（各専用Actionクラスは既にページサイズ対応済み）
